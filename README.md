# 🎬 Movie Ticket Booking App (Flutter)

A modern **Movie Ticket Booking App** built using Flutter.
This app allows users to browse movies, view details, select seats, and book tickets with an interactive UI.

---

## 🚀 Features

* 🏠 Beautiful Home Screen UI
* 🎬 Movie Detail Screen
* 🎟️ Seat Selection System (Interactive)
* 📅 Date Selection
* ⏰ Time Slot Selection
* 💰 Dynamic Price Calculation
* 🌙 Dark Theme UI
* 📱 Responsive Design

---

## 🛠️ Tech Stack

* **Flutter**
* **Dart**
* **Material UI**
* **State Management:** setState
